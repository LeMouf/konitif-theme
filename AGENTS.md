# Repository agent rules

## Dependency safety

- Do not install, download, execute, or add external dependencies without explicit user approval.
- Reuse the locked dependency graph and disable lifecycle scripts and audit during installation.

## Public package boundary

- This repository distributes generic theme tokens, visual mappings, ambience, depth, focus, and reusable presentation surfaces.
- Do not add product demonstrations, robot assets or settings, reference tools, QA laboratories, application policy, or partner-specific code.
- Runtime and workspace state are observed inputs. The theme projects them visually and never becomes their authority.
- Keep README and reference artifacts consumer-facing and in English.

## Repository operations

- Do not commit, push, tag, or publish without explicit user authorization.
